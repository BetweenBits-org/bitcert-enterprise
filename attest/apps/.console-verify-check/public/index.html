  • sk_test_ API 키 — 바로 발급됩니다
  • 비트코인에 기록하는 두 가지 경로 — 브라우저를 떠나지 않는 해시, 또는 문서 자체

합성 데이터, 테스트 체인 전용입니다. 이 배포는 비공개 테스트 체인에 앵커링하므로, 여기서 만들어진 것은 공개적으로 검증 가능한 증명이 아닙니다 (not a publicly verifiable proof). 모든 화면이 그렇게 밝히며, 번들도 자신의 네트워크를 스스로 적습니다.
