# Source assets

Held in the repository rather than generated by the build, because they are
**real output from a real anchoring run** and cannot be reproduced from source
alone.

| File | What it is |
|---|---|
| `anchored.txt` | A document that was actually hashed and anchored. |
| `anchored.bundle.json` | The proof bundle `apps/core` exported for it, with a three-level Merkle path from a five-leaf batch. |

Regenerate with `deploy/make-sample-anchor.sh` against a running regtest node.
A single-leaf batch would leave the Merkle path empty and the Evidence tab with
nothing to show, which is why the generator pads the batch.

`samples/` is build output and is gitignored; these are copied into it.
